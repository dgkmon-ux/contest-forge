# 심사표 — 제3회 ○○시 열린데이터 생활문제 해결 아이디어 공모전

요강에 항목명은 있으나 배점이 없다. 항목은 요강을 따르고 배점만 `idea-contest` 프리셋으로 채웠다.

## 항목별 득점 조건

**창의성 (30)** — 기존 서비스와 무엇이 다른지를 대조표로 제시해야 인정된다. 새로운 데이터 조합도 창의성으로 친다. ○○시 데이터를 남들이 안 쓰는 방식으로 결합하면 여기서 가장 크게 벌어진다.

**실현가능성 (25)** — 쓰려는 공공데이터가 실제로 개방되어 있고 즉시 받을 수 있는지가 핵심. 별도 신청·승인이 필요한 데이터에 의존하면 감점. 처리 흐름을 단계로 제시하면 오른다.

**기대효과 (25)** — 누구의 어떤 불편이 얼마나 줄어드는지. 대상 규모와 측정 방법을 함께 제시한다. 숫자는 출처가 있어야 하고, 없으면 측정 방법만 쓴다.

**완성도 (20)** — 화면 구성안 유무가 실질적으로 이 점수를 가른다. 요강이 구현물을 요구하지 않으므로 목업이 있는 제안과 없는 제안의 차이가 크다.

## 감점·탈락 조건

- 기출품·타 대회 수상작 (수상 취소)
- A4 5장 초과
- 파일명 규칙 위반
- ○○시 공공데이터를 실질적으로 쓰지 않고 소재로만 언급

## 심사 방식이 강제하는 것

- 서류 → 본선 2단계. **서류에서 걸러지므로 기획서 단독으로 완결되어야 한다.** 발표에서 설명하면 된다는 전제로 쓰면 본선에 못 간다.
- 블라인드 아님 → 소속·이력을 강점으로 쓸 수 있다.
- 본선 발표 7분 → 슬라이드 8장이 상한. 데모 연출에 2분 이상 배분.
