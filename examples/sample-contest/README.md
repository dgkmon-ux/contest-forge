# 형식 예시 — 가상 공모전 1건

**여기 있는 공모전은 실재하지 않는다.** 산출물이 어떤 모양이어야 하는지 보여주려고 만든 가상 사례다. 기관명·일정·수치 전부 가공이다.

`①recon`과 `②ideate`까지의 산출물만 담았다. `plan.md`는 `assets/plan.template.md`가 이미 골격을 보여주고, `deck.html`은 형식보다 주제에 좌우되므로 뺐다.

| 파일 | 어느 단계 | 무엇을 보여주는가 |
|---|---|---|
| `brief.md` | ① | 필수항목 표, `[미확인]` 마커, 게이트 판정 |
| `rubric.md` | ① | 요강 근거와 프리셋(추정)이 한 표에 섞이는 방식, 득점 조건 |
| `ideas.md` | ② | 자기추정 명시, 채점표, 공식 배점과 분리된 적합도 컬럼, 견적서의 약점 항목 |

## 이 예시로 확인할 것

1. **점수 컬럼이 `rubric.md`의 항목·배점과 정확히 일치하는가.** 예시 배점을 복붙해서 다른 숫자가 들어오면 실패다.
2. **주최사 적합도가 점수에 섞여 들어가지 않았는가.** 별도 컬럼이어야 한다.
3. **견적서 3개 모두 약점 항목이 채워져 있는가.** 비면 자기채점 편향을 막을 장치가 없다.
4. **근거 없는 수치가 없는가.** `[출처 필요]`로 남아 있어야 한다.
