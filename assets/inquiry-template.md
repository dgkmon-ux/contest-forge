# 주최·운영사 문의 템플릿

`[미확인 — 자료에 없음]` 항목이 남았을 때 쓴다. **사용자가 그대로 복사해 보낼 수 있는 형태로 만들어 제시한다.** 내가 대신 보내지 않는다.

## 원칙

- **한 통으로 모아 보낸다.** 나눠 보내면 회신이 나뉘고 늦어진다.
- 요강에 없는 것만 묻는다. **요강을 읽으면 나오는 것을 물으면 회신 우선순위가 떨어진다.**
- 각 질문에 **왜 필요한지를 한 줄** 붙인다. 담당자가 답하기 쉬워진다.
- 마감이 임박했으면 **회신 희망일을 적는다.** 남은 일수의 1/3 지점이 기본값이다.
- 연락처가 요강에 없으면 그 사실을 알리고, 대표 문의처·공고 게시판 문의를 대안으로 제시한다.

## 문의문 형식

```
제목: [<공모전명>] 요강 관련 문의 (<n>건)

안녕하세요. <공모전명>에 참가를 준비 중인 <개인/팀>입니다.
공고와 첨부를 확인했으나 아래 항목이 확인되지 않아 문의드립니다.

1. <질문>
   (<왜 필요한지 한 줄>)

2. <질문>
   (<왜 필요한지 한 줄>)

...

접수 마감이 <YYYY-MM-DD>인 점을 고려해 <YYYY-MM-DD>까지 회신 주시면
준비에 큰 도움이 되겠습니다. 감사합니다.
```

## 자주 비어 있는 항목 — 여기서 골라 쓴다

요강에 없으면 아래 문장을 그대로 쓴다. **해당하지 않는 것은 넣지 않는다.**

**진행 가능 여부 (①게이트 차단 대상)**

- 출품작의 지식재산권 귀속과 주최측 활용 범위는 어떻게 되는지요?
  (수상 후 자체 개발·창업으로 이어갈 수 있는지 판단이 필요합니다)
- 타 공모전 수상작이나 기제출작을 수정해 제출할 수 있는지요?
  (기존 작업물의 활용 가능 범위를 확인하려 합니다)
- 동일인·동일 팀이 복수 과제 또는 복수 분야에 응모할 수 있는지요?
- 팀원 중 <해당 조건>인 경우도 참가 자격에 해당하는지요?

**제출 규격 (④단계 산출물 형태를 결정)**

- 기획서의 분량 상한(장수 또는 페이지)이 정해져 있는지요?
- 지정 양식 파일이 별도로 있는지요? 있다면 받을 수 있는 경로를 알려주시면 감사하겠습니다.
- 제출 파일의 파일명 규칙이나 용량 제한이 있는지요?
- 제출물에 <별도 산출물 이름>이 포함돼 있는데, 허용 형식(확장자)과 규격을 알려주실 수 있는지요?
  (문서 내 삽입으로 갈음되는지, 별도 파일이어야 하는지 확인이 필요합니다)
- 접수 마감 시각은 몇 시인지요?

**심사 방식 (문서 작성 방식을 결정)**

- 심사가 블라인드로 진행되는지요? 소속·성명을 제출물에 기재해도 되는지 확인하고자 합니다.
- <n>차 심사의 발표는 대면인지 온라인인지요? 시연 장비·인터넷 사용이 가능한지요?
- 발표 시간 <n>분에 질의응답이 포함되는지요?
- 시연 영상 제출이 필요한지요? 필요하다면 길이·형식 제한을 알려주시면 감사하겠습니다.

**데이터·구현 조건 (`analysis-model`·`hackathon` 유형)**

- 주최측에서 제공하는 데이터셋이나 분석 환경이 있는지요?
- <특정 데이터>를 <경로>를 통해 수집해 사용하는 것이 허용 범위에 해당하는지요?
- 소스코드나 분석 스크립트를 함께 제출할 수 있는지요? 심사에 반영되는지요?
- 외부 오픈소스 라이브러리·사전학습 모델의 사용 범위에 제한이 있는지요?

## 회신을 못 받았을 때

- **추측해서 만들지 않는다.** 대신 **가장 보수적인 규격**으로 만든다 — 분량은 짧게, 형식은 PDF·PPT 양쪽, 소속 표기는 빼고.
- 무엇을 가정했는지 `brief.md`와 `STATE.md`에 남기고, 회신이 오면 즉시 재조정한다.
- 회신 없이 ④를 마무리해야 하면, 사용자에게 **가정 목록과 각 가정이 틀렸을 때의 결과**를 보고한다.
