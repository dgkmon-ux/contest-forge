## 1. 제안 개요

무엇이 달라지고 있는가(변화) → 그런데 지금 체계는 무엇을 못 하는가(공백) → 그래서 이것을 만든다(제안).

핵심 파이프라인을 한 줄로:

```text
A → B → C → D → E
```

핵심 질문 한 문장:

> "<기존 질문>"을 넘어
> "<우리가 던지는 질문>"

| | | |
